# Problem Statement

Small cafes often manage orders, billing, customer records, and inventory manually. This can lead to errors, delays, and difficulty in maintaining records.

The objective of this project is to develop a Python-based Cafe Management and Inventory System that automates these tasks. The system allows customers to place orders, generates bills, stores customer information, and manages inventory records efficiently.

# Scope of the Project

The project focuses on:

* Customer Registration and Login
* Menu Display
* Order Placement
* Billing System
* Inventory Management
* Order History Storage
* File-Based Data Storage

# Target Users

* Cafe Owners
* Cafe Staff
* Customers

# High-Level Features

* Secure Customer Login
* Food Ordering System
* Cart Management
* Automatic Bill Generation
* Inventory Tracking
* File Handling for Data Storage
* Order History Management
