>>Cafe Management and Inventory System

>>Project Description

This is a beginner-friendly Python-based Cafe Management and Inventory System. The project helps manage customer orders, billing, menu items, and inventory records through a simple command-line interface.

>>Features

- Customer Login and Registration
  {Username=admin, password=1234}
- Cafe Menu Display
- Add Items to Cart
- Order Placement
- Bill Generation
- Inventory Management
- Order History
- File Handling for Data Storage

>>Requirements

- Python 3.x

>>How to Run

1. Download or clone the repository.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run the program using:


python "Cafe Management System.py"
